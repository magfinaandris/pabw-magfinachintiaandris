### Token yang saya tetapkan

| Token | Nilai | Untuk apa |

| --color-primary | #A3123F | tombol, tautan, judul, penanda |
| --color-fg | #14121A | warna teks utama |
| --color-bg | #F4F5F8 | latar halaman |
| --radius-md | 0.5rem | sudut tombol, kartu, isian |
| --space-4 | 1rem | jarak standar antar elemen |

Kriteria selesai saya: mengubah --crimson-700 (dan --color-primary) di tokens.css harus
mengubah warna tombol, tautan, judul, dan garis fokus.
